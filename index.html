Review Changes

Review the saved decisions and comments, then share or save the change report to send to Miguel / lmviterbo.

The change report is for reading and reviewing. The map file keeps the complete working map so you can continue editing it elsewhere.

Using the editor

  1. Enter your Editor Name. You can use your EuroBillTracker username.
  2. Find a dot by clicking the map or entering its two numbers.
  3. Choose its classification and write your reason or comment.
  4. Click Save change. Repeat for any other dots you want to review.
  5. Click Review Changes, then Share Change Report if it is available. Choose an app, select Miguel / lmviterbo as the recipient, and send the attachment. You can always use Save Change Report to download the report and attach it yourself.

The sharing menu and available apps depend on your browser and device. The Share button appears only when this HTML report can be shared. Cancelling the menu returns you to the editor; if sharing fails, use Save Change Report.

Your edits affect only your own working copy. Save change updates that copy, and Save Map File downloads it. Neither action changes the shared starting map or the live Dot Safari app.

Your work, including an unfinished comment, is saved automatically in this browser. Refreshing or reopening the editor in the same browser normally restores it. If automatic saving is unavailable, the editor will tell you.

To continue on another computer or in another browser, save your current change, then use Save Map File. Open the editor there and choose Open Map File to load the copy you saved. You can also save a map file whenever you want a separate copy of your work.

For the map manager

Keeping and moving your work

Save Map File downloads a new copy; it does not overwrite the file you opened. That copy keeps every dot, comment, editor name, history entry and source reference. Use it before clearing browser data or moving or replacing a downloaded editor. Keep the downloaded editor in the same place and use the same browser to retain its draft.

Each collaborator has their own browser draft. It is not shared automatically. Private browsing clears its draft when the private session ends. If browser saving fails, save your current change and use Save Map File before closing.

Starting map and history

The Starting map reference identifies the map you began with. It stays fixed as you edit and when your draft is restored, and also appears in the change report. Opening a map file starts a new reference. An older draft may not have recorded its starting reference; its saved work is still kept.

The history and report include earlier visits, with repeated saves of the same classification and comment by the same editor shown only once. The original records remain in the map file. You can save a new comment without changing the classification. An identical repeat of your latest classification and comment is not saved twice. Undo and Redo apply during the current visit and remain visible in the history. A reversed edit is labelled Undone; using Redo removes that label from the original edit. A Redo that is later reversed is also labelled Undone; that Redo record keeps its label if another Redo is recorded. The latest saved comment shows the most recent edit that has not been undone. Save the map file and report again after a correction to update your downloaded copies.

Exported filenames and dates

Exported filenames include the map revision, editor name and export time. Filename times use UTC (UTC+00:00), in YYYYMMDD-HHmm format, without seconds or a timezone suffix. Unicode letters, spaces and emojis are kept. Characters that cannot be used in filenames are replaced with underscores; exceptionally long names are shortened in filenames only. Names inside the map and report are kept unchanged.

The Starting map time is shown in UTC. If the source records only a date, only that date is shown. History times in the report are shown in Lisbon local time.

Map display

Orange dots can be Euro-use targets. Unconquerable Euro land is dark grey with crossed hatching; Sea has blue diagonal stripes; Foreign land is red. Unreviewed dots have no classification colour or pattern. All classifications except Conquerable are excluded from Euro-use targets.

The opacity slider fades the classification colours. Crossed lines keep a minimum visibility while the overlay is on, so Unconquerable dots remain recognisable over the map. At 0%, all classification colours and patterns are hidden. Map imagery needs internet access; the grid, editing and exports still work without it. Repeated copies of the world share the same saved dots.
